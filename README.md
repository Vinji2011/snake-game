# Little Arcade

A tiny collection of arcade games that runs in a browser toolbar popup. It uses plain HTML, CSS, and JavaScript; no build step or dependencies are needed.

## Install in Chrome or Edge

1. Open `chrome://extensions` or `edge://extensions`.
2. Turn on **Developer mode**.
3. Choose **Load unpacked** and select this folder.
4. Open the Little Arcade toolbar button and pick a game.

## Games and controls

- **Snake:** Arrow keys or WASD to steer.
- **Pac-Man:** Arrow keys or WASD to move through the maze and collect every dot.
- **Ping Pong:** Up/Down or W/S to move your paddle; keep returning the ball.
- **Run & Jump:** Up, W, or Space to jump over randomly spaced cactus groups, including tight clusters.

The on-screen direction pad works for movement games. Use the pause button or Space to pause (Space jumps while running), the circular-arrow button to restart, and the home button to return to the menu. Each game's best score is saved separately in the browser.
